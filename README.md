# 📋 Система обработки задач (Queue)

## 📌 Почему очередь на массиве?

Для системы обработки задач выбрана структура **очередь на основе динамического массива (list)** по двум причинам:

1. **Простота и наглядность** — задачи обрабатываются в порядке поступления (FIFO), массив в Python идеально подходит для небольшого количества задач.

2. **Быстрый доступ к элементам** — `front()` выполняется за O(1), а встроенные методы Python делают код лаконичным.

Дополнительно: можно легко вывести все задачи с индексами и расширить функционал (например, сортировка по приоритету).

---

## 🧱 Структура проекта

### `Task` — задача
```python
class Task:
    id           # уникальный идентификатор (задаётся пользователем)
    description  # описание задачи
    priority     # приоритет (чем выше число, тем важнее)
```

### `Queue` — очередь задач
```python
class Queue:
    items        # список задач
```

---

## ⚙️ Функции очереди

| Функция | Описание |
|---------|----------|
| `enqueue(task)` | Добавляет задачу в конец очереди.  |
| `dequeue()` | Удаляет и возвращает первую задачу из очереди. |
| `front()` | Возвращает первую задачу без удаления. |
| `isEmpty()` | Проверяет, пуста ли очередь. |
| `printqueue()` | Выводит все задачи с нумерацией, приоритетом и id |

---

## 🚀 Быстрый старт

```python
queue = Queue()

# Создаём задачи
task1 = Task(1, "Сделать кофе", 1)
task2 = Task(2, "Сделать отчет", 3)
task3 = Task(3, "Проверить почту", 2)

# Добавляем в очередь
queue.enqueue(task1)
queue.enqueue(task2)
queue.enqueue(task3)

# Выводим все задачи
queue.printqueue()

# Смотрим первую задачу
print(f"Первая задача: {queue.front().description}")

# Выполняем (удаляем) первую задачу
queue.dequeue()

# Проверяем, не пуста ли очередь
print(f"Очередь пуста: {queue.isEmpty()}")

# Смотрим новую первую задачу
print(f"Теперь первая: {queue.front().description}")
```

**Вывод:**
```
================= СПИСОК ЗАДАЧ =================
1. Сделать кофе (приоритет = 1, id = 1)
2. Сделать отчет (приоритет = 3, id = 2)
3. Проверить почту (приоритет = 2, id = 3)
Первая задача: Сделать кофе
Очередь пуста: False
Теперь первая: Сделать отчет
```
