# Сервис коротких ссылок (MapLink)

## Описание

Простой сервис для хранения коротких ссылок, реализованный на основе словаря (HashMap). Позволяет создавать короткие коды для длинных URL, проверять их существование и получать оригинальные ссылки.

## Структура проекта

### `MapLink` - хранилище ссылок

```python
class MapLink:
    map    # словарь, где ключ - короткий код, значение - длинная ссылка
```

## Функции сервиса

| Функция | Описание | Сложность |
|---------|----------|-----------|
| `addlink(shortlink, link)` | Добавляет пару короткий код-ссылка. Если ссылка уже существует, сообщает об этом | O(n) при проверке дубликата, O(1) при вставке |
| `isSLink(shortlink)` | Проверяет, существует ли короткий код в хранилище | O(1) |
| `getLink(shortlink)` | Возвращает длинную ссылку по короткому коду или None | O(1) |
| `printShortLinks()` | Выводит все короткие коды | O(n) |

## Быстрый старт

```python
map = MapLink()

# Добавляем ссылки
map.addlink("gh", "https://github.com")
map.addlink("yt", "https://youtube.com")

# Проверяем существование
print(map.isSLink("gh"))  # True
print(map.isSLink("fb"))  # False

# Получаем ссылку
print(map.getLink("gh"))  # https://github.com

# Выводим все короткие коды
map.printShortLinks()
```

## Интерактивное меню

Программа поддерживает интерактивное меню с выбором действий:

```
1. Добавить ссылку и короткий код на нее
2. Проверить существует ли короткий код
3. Получить ссылку по короткому коду
4. Вывести все короткие коды
Все остальные значения - закончить работу с программой
```

## Особенности реализации

| Особенность | Описание |
|-------------|----------|
| **Проверка дубликатов ссылок** | При добавлении проверяется, не существует ли уже короткий код для этой ссылки |
| **Защита от перезаписи** | Если короткий код уже существует, он не будет перезаписан (используется `setdefault`) |

## Структура данных

```
map = {
    "gh": "https://github.com",
    "yt": "https://youtube.com",
    "go": "https://google.com"
}
```

Ключ - короткий код (строка), значение - полная ссылка (строка).
