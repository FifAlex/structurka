# Обход бинарного дерева (Binary Tree Traversal)

## Описание

Программа для работы с бинарными деревьями с интерактивным интерфейсом. Позволяет создавать несколько именованных деревьев, добавлять узлы вручную, выполнять все основные виды обхода (включая обход в ширину) и проверять дерево на симметричность относительно корня.

## Структура проекта

### TreeNode — узел дерева

```python
class TreeNode:
    value    # значение узла (целое число)
    left     # ссылка на левое поддерево
    right    # ссылка на правое поддерево
```

### MapTree — хранилище деревьев

```python
class MapTree:
    map      # словарь, где ключ — название дерева, значение — корень (TreeNode)
```

Позволяет хранить несколько независимых деревьев и переключаться между ними.

## Функции для работы с хранилищем

| Функция | Описание |
|---------|----------|
| `addtree(name, koren)` | Добавляет дерево с указанным названием в хранилище |
| `getTree(name)` | Возвращает корень дерева по названию или None |
| `printNames()` | Выводит названия всех сохраненных деревьев |

## Функции обхода дерева

| Функция | Описание | Порядок обхода |
|---------|----------|----------------|
| `preorder(root)` | Прямой обход | Корень, левое поддерево, правое поддерево |
| `inorder(root)` | Симметричный обход | Левое поддерево, корень, правое поддерево |
| `postorder(root)` | Обратный обход | Левое поддерево, правое поддерево, корень |
| `level_to_order(root)` | Обход в ширину (по уровням) | Узлы обрабатываются уровень за уровнем слева направо |
| `check_symmetry(node)` | Проверка симметричности дерева | Рекурсивное сравнение левого и правого поддеревьев |
| `is_mirror(left, right)` | Вспомогательная функция проверки зеркальности двух поддеревьев | Сравнивает значения и рекурсивно проверяет структуру |

## Интерактивное меню

Программа поддерживает интерактивное меню с выбором действий:

```
0. Выбрать текущее дерево
1. Создать дерево
2. Добавить узел в существующее дерево
3. Проверить симметрию дерева
4. Вывести все названия деревьев
5. Провести прямой обход дерева и вывести его
6. Провести симметричный обход дерева и вывести его
7. Провести обратный обход дерева и вывести его
8. Сделать обход в ширину и вывести его
Все остальные значения — закончить работу с программой
```

## Быстрый старт

```python
# Создаем дерево вручную
root = TreeNode(1)
root.left = TreeNode(2)
root.right = TreeNode(3)
root.left.left = TreeNode(4)
root.left.right = TreeNode(5)

# Прямой обход
print(preorder(root))        # [1, 2, 4, 5, 3]

# Симметричный обход
print(inorder(root))         # [4, 2, 5, 1, 3]

# Обратный обход
print(postorder(root))       # [4, 5, 2, 3, 1]

# Обход в ширину
print(level_to_order(root))  # [1, 2, 3, 4, 5]

# Проверка на симметрию
print(check_symmetry(root))  # False
```

## Особенности реализации

| Особенность | Описание |
|-------------|----------|
| Несколько деревьев | Можно создавать и хранить несколько именованных деревьев одновременно |
| Интерактивное добавление узлов | Навигация по дереву с выбором левого (l) или правого (r) поддерева |
| Рекурсивные обходы | Прямой, симметричный и обратный обходы реализованы рекурсивно |
| Обход в ширину | Реализован с использованием очереди (`collections.deque`) |
| Проверка симметрии | Рекурсивное сравнение структуры и значений левого и правого поддеревьев |
