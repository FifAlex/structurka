# Моделирование автобусного маршрута на двусвязном списке

## Почему двусвязный список?

Для моделирования автобусного маршрута выбрана структура **двусвязного списка** вместо динамического массива или односвязного списка по двум причинам:

1. **Вставка в середину маршрута** — при добавлении новой остановки по координатам нужно вставить её между двумя существующими. В двусвязном списке это O(1) после нахождения места, в массиве пришлось бы сдвигать все элементы — O(n).

2. **Движение в обоих направлениях** — для разворота маршрута (`reverseList`) и обратного прохода нужны ссылки в обе стороны. Односвязный список позволяет двигаться только вперёд.

---

## Структура проекта

### `Coord` — координаты на плоскости
```python
class Coord:
    x, y           # координаты
    distance_to()  # расстояние до другой точки
```

### `Ostanovka` — остановка
```python
class Ostanovka:
    name           # название остановки
    coords         # координаты (Coord)
    time_to_next   # время до следующей остановки (мин)
```

### `DoublyNode` — узел списка
```python
class DoublyNode:
    ostanovka      # данные (объект Ostanovka)
    prev           # ссылка на предыдущий узел
    next           # ссылка на следующий узел
```

### `DoublyLinkedList` — маршрут
```python
class DoublyLinkedList:
    head           # первый узел
    tail           # последний узел
    size           # количество остановок
```

---

## Функции маршрута

| Функция | Описание |
|---------|----------|
| `add_ostanovka(ostanovka)` | Добавляет остановку автоматически по координатам: находит ближайшую существующую остановку и вставляет новую перед или после неё. Время рассчитывается через `AVERAGE_SPEED = 1.5` |
| `display_forward()` | Выводит маршрут от начала к концу с названиями, координатами и временем |
| `where_through_N(N, name)` | Показывает, где окажется автобус через `N` остановок после указанной |
| `where_through_time(time, name)` | Показывает, где будет автобус через указанное количество минут |
| `reverseList()` | Разворачивает маршрут в обратном направлении с пересчётом времени |
| `generate_report(filename)` | Сохраняет текстовый отчёт с общей статистикой и таблицей остановок |

---

## Быстрый старт

```python
route = DoublyLinkedList()

# Добавляем остановки
route.add_ostanovka(Ostanovka("Вокзал", Coord(0, 0)))
route.add_ostanovka(Ostanovka("Центр", Coord(10, 0)))
route.add_ostanovka(Ostanovka("Парк", Coord(20, 0)))

# Показываем маршрут
route.display_forward()

# Где автобус через 3 остановки после Вокзала?
route.where_through_N(3, "Вокзал")

# Разворачиваем маршрут
route.reverseList()

# Сохраняем отчёт
route.generate_report("marshrut.txt")
```

## Константа

```python
AVERAGE_SPEED = 1.5  # условных единиц координат в минуту
```

Время движения между остановками вычисляется как `расстояние / AVERAGE_SPEED`. При необходимости значение можно изменить в коде.
